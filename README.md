# RS Paper and Packaging - পেপার ফ্যাক্টরি ইআরপি ও হিসাব ব্যবস্থাপনা সফটওয়্যার

**RS Paper and Packaging** পেপার ফ্যাক্টরির জন্য তৈরি একটি আধুনিক, স্বয়ংক্রিয় এবং সহজে ব্যবহারযোগ্য ইনভেন্টরি, হিসাব, ডিজিটাল খাতা ও বিলিং সফটওয়্যার।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Core Features)

### ১. পেপার ক্রয় ব্যবস্থাপনা (Purchase Management)
- সাপ্লায়ারের নাম, ফোন নম্বর, ঠিকানা ও তারিখ।
- **Tissue Paper** এবং **Cutting / News Paper** এর পরিমাণ (কেজি) ও দর।
- সর্বমোট ক্রয়মূল্য, পরিশোধিত টাকা এবং **সাপ্লায়ার আর কত টাকা পাবে (দেনা/বাকি)** স্বয়ংক্রিয় হিসাব।
- প্রতিটি ক্রয়ের সাথে সাথে গোডাউনের স্টক বৃদ্ধি পায়।

### ২. পেপার বিক্রয় ও ক্যাশ মেমো (Sales & Billing Management)
- কাস্টমারের নাম, ফোন নম্বর, ঠিকানা ও তারিখ।
- **Tissue Paper** এবং **Cutting / News Paper** এর পরিমাণ (কেজি) ও বিক্রয় দর।
- স্টক চেক করে স্বয়ংক্রিয় ভ্যালিডেশন।
- সর্বমোট বিক্রয়মূল্য, নগদ জমা এবং **কাস্টমার কত টাকা বাকি রাখল (পাওনা)** তাৎক্ষণিকভাবে হিসাব।
- প্রিন্ট-রেডি আকর্ষণীয় ক্যাশ মেমো ও চালান তৈরির সুবিধা।

### ৩. অ্যাপের ভেতরে কাস্টমার ও সাপ্লায়ার ডিজিটাল খাতা (Party Accounts Ledger)
- কম্পিউটার বা ফোল্ডারের ঝামেলা ছাড়াই সম্পূর্ণ অ্যাপের ভেতরে প্রতিটি কাস্টমার ও সাপ্লায়ারের জন্য আলাদা **ডিজিটাল খাতা (Khata)**।
- প্রতিটি পার্টির মোট লেনদেন, মোট পরিশোধিত টাকা ও বর্তমান বাকির রিয়েল-টাইম হিসাব।
- নতুন থেকে পুরনো তারিখ অনুযায়ী সম্পূর্ণ লেনদেনের খতিয়ান।
- খাতা থেকেই সরাসরি নতুন চালান ও টাকা জমা/পরিশোধের ভাউচার এন্ট্রি।

### ৪. স্বয়ংক্রিয় গোডাউন স্টক ব্যবস্থাপনা (Automated Warehouse Stock)
- **Tissue Paper** এবং **Cutting / News Paper** এর মোট ক্রয়, মোট বিক্রয় ও অবশিষ্ট স্টকের লাইভ ক্যালকুলেশন।
- গড় ক্রয়মূল্যের ভিত্তিতে গোডাউনে থাকা মালের মোট টাকার মান (Stock Valuation)।

### ৫. Supabase ক্লাউড ডাটাবেজ ইন্টিগ্রেশন (Supabase PostgreSQL Database)
- ক্লাউড ডাটাবেজ হিসেবে **Supabase** এর সাথে সম্পূর্ণ রিয়েল-টাইম সিঙ্ক।
- অ্যাপে যেকোনো লেনদেন করলেই তা সরাসরি Supabase ক্লাউডে জমা হয়।
- অফলাইনেও নিরবচ্ছিন্ন কাজ চালানোর জন্য লোকাল ক্যাশ সাপোর্ট।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

- **Frontend:** React.js, Tailwind CSS, Lucide Icons, Vite
- **Backend:** Node.js, Express.js
- **Database:** Supabase (PostgreSQL) + Local JSON Engine

## 🚀 কীভাবে চালু করবেন (How to Run)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. এনভায়রনমেন্ট কনফিগারেশন:
`.env.example` ফাইলটি কপি করে `.env` তৈরি করুন এবং আপনার Supabase URL ও Key দিন:
```env
PORT=5000
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-supabase-anon-key
```

### ৩. সার্ভার চালু করুন:
```bash
npm start
```
অথবা এক ক্লিকে চালাতে প্রজেক্টের **`start.bat`** ফাইলে ডাবল ক্লিক করুন।

### ৪. ব্রাউজারে অ্যাপ্লিকেশন ওপেন করুন:
👉 **`http://localhost:5000`**
